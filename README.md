# hello-carbon

Тестове репо: лендінг hello world (прив'язане до картки «Створити тестовий репозиторій з лендінгом Hello world, CI/CD і керуванням агентом»)

Репо веде Darvin: тікет → агент заводу → PR → перевірки → злиття → сайт на GitHub Pages.

- Перевірка: `npm ci && npm test && npm run build` (docs/agents/verify.md).
- Сторінка: `index.html`, збірка кладе її в `dist/`.
